# 02. Colors — 색 7개

## GospelFix 프로필 — 실제 값

| 이름 | 값 | shadcn 변수 | 쓰는 곳 |
|---|---|---|---|
| 바탕 | `#F4F5F7` | `--background` | 화면 배경 (`body`) |
| 표면 | `#FFFFFF` | `--card`, `--popover` | 카드(`.card`), 리스트 컨테이너, Bottom Sheet |
| 글자 기본 | `#14151A` | `--foreground` | 제목, 본문, 이름 |
| 글자 보조 | `rgba(20, 21, 26, 0.55)` | `--muted-foreground` | 날짜, 부가 정보, 라벨 |
| 테두리 | `rgba(20, 21, 26, 0.08)` (진한 버전 `0.14`) | `--border`, `--input` | 카드 경계, 구분선, 입력 요소 테두리 |
| 포인트 색 | `#14151A` (글자 기본과 동일) | `--primary` | 주 버튼(공유하기, 이미지로 저장) 배경 |
| 포인트 색 옅은 것 | `#EEF0F3` | `--secondary`, `--accent`, `--muted` | 칩/태그 배경, hover 배경 |

바탕과 표면 중에 **표면**이 더 밝다 (`#FFFFFF` > `#F4F5F7`) — 카드가 배경 위로 살짝 뜨는 느낌(방식 B). 다만 명도 차가 크지 않아(2~4%) 그림자 없이도 자연스럽게 구분되고, 실제로는 대부분 카드가 테두리(`--border`)로 경계를 보강한다.

## 정해진 것

- **포인트 색은 1개, 그리고 무채색이다.** 이 프로젝트에는 브랜드 컬러(청록/파랑 등 채도 있는 색)가 없다 — "포인트"는 색상이 아니라 **명도 대비**(어두운 배경 + 흰 글자)로 만든다. 히어로 배경의 블러쉬 그라데이션(`--color-hero-glow-1/2/3`)은 장식 전용이며 포인트 색이 아니다.
- **색 공간은 HEX + rgba 혼용.** 순수 배경/전경색은 HEX, 투명도가 필요한 테두리·보조 텍스트는 `rgba(20, 21, 26, α)`로 표기한다. OKLCH는 사용하지 않는다 (포인트 색이 무채색 하나뿐이라 색상각 교체의 이점이 없음).
- **destructive(위험) 색은 현재 미사용.** 삭제·취소 등 되돌릴 수 없는 액션이 이 프로필 페이지에는 없다. 추후 추가 시에만 표준 빨강 계열을 새로 정의한다.

## 체크리스트
- [x] 포인트 색이 1개인가 — 예 (무채색 `#14151A`)
- [x] 바탕/표면 밝기 관계를 한 줄로 적었는가 — 표면이 더 밝음
- [x] 글자 기본/보조가 바탕 대비 대비율을 만족하는가 — 기본 `#14151A` on `#F4F5F7`은 15:1 이상(AAA), 보조는 대략 6:1
- [x] 새 색을 추가하기 전에 "이 색이 없으면 못 만드는 화면이 있나?"를 자문했는가 — 히어로 그라데이션 3색 외 추가 색 없음
- [x] HEX와 OKLCH 중 하나로 표기를 통일했는가 — HEX + rgba 혼용으로 통일 (OKLCH 미사용)
