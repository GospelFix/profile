# 01. Style Reference — 맨 위 세 줄

# GospelFix 프로필 — Style Reference
> 소윤호 / GospelFix 대표의 개인 프로필 페이지. 절제된, 또렷한, 신뢰감 있는.

**Theme:** light (다크모드 없음 — 프로젝트 전체가 라이트 테마로 고정)
**Platform:** mobile 390×844 (기준) / desktop 1440×900 (768px 이상에서 `.container`가 카드형으로 중앙 정렬)

---

## 선정 이유

- **절제된** — 액센트 컬러 없이 무채색(그레이스케일)만 사용. 포인트는 색이 아니라 명도 대비(어두운 버튼/글자)로 만든다.
- **또렷한** — 연락처·소셜·포트폴리오가 리스트/카드로 명확히 구획되고, 배지·태그로 정보를 라벨링한다.
- **신뢰감 있는** — 배경(#F4F5F7)과 표면(#FFFFFF)의 명도 차, 테두리 사용이 규칙적이라 화면마다 카드가 들뜨거나 가라앉지 않는다.

세 단어 모두 "장식보다 구조" 방향을 가리킨다 — 그라데이션·글로우 같은 장식 요소는 히어로 배경(`--color-hero-glow-*`) 한 곳에만 예외적으로 존재하며, 나머지 전체는 무채색 + 테두리/그림자로 구조를 드러낸다.
