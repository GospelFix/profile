# 08. Guidelines — 하지 말 것 (가장 중요한 파일)

## GospelFix 프로필 — 실제 규칙

### DO
- 포인트 색(`--primary`, 무채색 `#14151A`)은 주 버튼 배경에만 쓴다 — 제목·아이콘·구분선에 쓰지 않는다
- 화면 하단 고정 주 버튼은 하나("프로필 공유하기"). Bottom Sheet 안의 액션 버튼은 시트가 열려 있을 때만 유효한 별도 컨텍스트로 취급한다
- 카드는 테두리 1px로만 구분한다 (06번) — 그림자를 섞지 않는다
- 가까운 것은 붙이고 먼 것은 띄운다 (04번 묶임 규칙: 아이콘-글자 8px, 섹션 간 24px 이상)
- 색은 `--color-*`(또는 09번의 shadcn 별칭 변수)로 참조한다 — HEX/rgba를 컴포넌트에 직접 박지 않는다
- 아이콘은 반드시 Lucide 이름에서 고른다 (07번) — 손으로 그린 커스텀 SVG를 새로 추가하지 않는다
- 모서리는 05번의 파생 스케일(`--radius`, `-sm/-md/-lg/-xl`)에서만 고른다

### DON'T
- 02번 색상표에 없는 채도 있는 색(브랜드 컬러)을 추가하지 않는다 — 이 프로젝트는 무채색 하나만 포인트로 쓴다
- 05번 스케일에 없는 모서리 값을 새로 만들지 않는다 (원형은 반드시 `9999px`, `%`나 절반 계산 금지)
- 카드류에 그림자를, 버튼/컨테이너에 그림자가 없는 상태를 섞어 쓰지 않는다 (06번에서 정한 레이어 기준을 그대로 따른다)
- 그라데이션은 히어로 배경(`--color-hero-glow-*`) 한 곳 외에는 쓰지 않는다
- 글자에 그림자를 넣지 않는다
- 다크 테마를 만들지 않는다 (01번에서 라이트 하나로 고정)

## 겪은 문제 (실제 기록)

| 증상 | 원인 | 해결 |
|---|---|---|
| 버튼 모서리가 16px인데 `--radius-md`(10px)와 안 맞음 | `--radius-*`를 정의만 해두고 컴포넌트는 리터럴 16px를 직접 씀 | 05번에서 `--radius`(기준값)를 16px로 재정의하고 리터럴을 `var(--radius)`로 교체 |
| `docs/design.md`(당시 이름)와 `docs/DESIGN.md`가 같은 파일로 덮어써짐 | macOS(APFS)가 대소문자를 구분하지 않는 파일시스템이라 대소문자만 다른 두 경로가 같은 파일로 취급됨 | 이후 `DESIGN.md`를 `design.md`로 통일하고, `design-system.md`처럼 베이스 이름 자체가 다른 파일과만 공존시킨다 — 이 프로젝트 문서 전체에서 대소문자만 다른 파일명을 만들지 않는다 |
| `.card`(14px)가 버튼(16px)보다 작음 (05번 원칙 위반) | 별도로 성장한 컴포넌트라 기준값 없이 각자 값을 가짐 | 2px 차이라 시각적으로 감지되지 않는 수준으로 유지, 새 카드는 16px 이상 우선 검토 |
| `.qr-sheet-handle`(40×4px)이 알약이 아니라 찌그러진 타원으로 보임 | `--radius-full`을 `50%`로 정의함 — `%`는 박스의 가로/세로에 각각 따로 적용되어 정사각형이 아닌 요소에서는 타원이 됨(40px 기준 20px + 4px 기준 2px) | `--radius-full`을 `9999px`로 변경. 절대 길이 값은 짧은 변의 절반으로 자동 clamp되어 정사각형(아바타·버튼)에서는 기존과 동일한 원, 가늘고 긴 요소(핸들바)에서는 올바른 알약 모양이 됨 |
| `font-weight`가 400/500/600/700/800 5종으로 흩어짐 | 03번 규칙(2종+예외1) 없이 컴포넌트마다 다르게 지정됨 | 신규 컴포넌트는 400/700(예외 800)만 사용, 기존 500/600은 점진적으로 정리 |
