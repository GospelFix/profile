# 04. Spacing — 간격

## GospelFix 프로필 — 실제 값

- 간격은 4px 기준 배수(`4·8·12·16·20·24`)를 핵심 스케일로 쓴다. 그 사이 값(예: 10px, 14px, 18px)은 신규 컴포넌트에 쓰지 않는다
- 화면 좌우 여백 `20px` (`--space-5`, `.card { margin: 0 20px }`)
- 카드 안쪽 여백 `18~20px` (`.list-item { padding: 18px 20px }`)
- 카드와 카드 사이 `16px` (`--space-4`, 섹션 간 기본 간격)
- 요소 안쪽의 작은 간격(아이콘-글자, 라벨-값 등) `8px` (`--space-2`)

## 전체 스케일 (`--space-*`, `assets/css/style.css` `:root`)

| 변수 | 값 |
|---|---|
| `--space-1` | 4px |
| `--space-2` | 8px |
| `--space-3` | 12px |
| `--space-4` | 16px |
| `--space-5` | 20px |
| `--space-6` | 24px |
| `--space-8` | 32px |
| `--space-10` | 40px |
| `--space-12` | 48px |

> 04번 원칙(6단계 이내)보다 3단계 많다 — `--space-8/10/12`는 큰 영역(섹션 간 상하 여백, 히어로 상하 패딩 등)에 쓰는 확장 구간이고, 실제로 촘촘한 자리에는 상위 6개(4~24px)만 쓰인다. **신규 컴포넌트의 자리별 값(화면 여백/카드 안쪽/카드 사이/작은 간격)은 반드시 4~24px 구간 안에서만 고른다.**

## 묶임 규칙 확인

카드 사이(16px) < 카드 안쪽(18~20px) ≤ 화면 좌우 여백(20px) — 04번이 요구하는 순서를 만족한다. 가까운 요소(아이콘+글자, 라벨+값)는 `--space-1`~`--space-2`(4~8px)로 붙이고, 먼 섹션은 `--space-6` 이상으로 띄운다.

## 알려진 기술 부채

일부 컴포넌트(`.hero-tags` gap: 6px, `.contact-button` gap: 8px 등)가 `var(--space-*)` 변수 대신 리터럴 px 값을 직접 쓴다. 값 자체는 4의 배수라 스케일을 벗어나지는 않지만, 신규 작업 시에는 리터럴 대신 반드시 `var(--space-N)`으로 참조한다.

## 체크리스트

- [x] "그 사이 값은 쓰지 않는다" 금지 문장이 포함되어 있는가
- [x] 자리별(좌우 여백/카드 안쪽/카드 사이) 값을 개별 지정했는가
- [x] 카드 사이 < 카드 안쪽 ≤ 화면 좌우 여백 순서가 지켜졌는가
- [ ] 스케일이 6단계 안쪽인가 — 핵심 6단계 + 확장 3단계(예비), 위 표에서 근거 명시
