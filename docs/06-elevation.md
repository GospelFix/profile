# 06. Elevation — 깊이

## GospelFix 프로필 — 실제 값 (레이어 절충형)

```
## Elevation
- 화면에 붙어있는 요소(컨테이너, 버튼) — 옅은 그림자 + 테두리 병행
- 화면 위에 떠서 다른 것을 가리는 요소(Bottom Sheet, Toast) — 진한 그림자
```

| 레이어 | 그림자 | 테두리 |
|---|---|---|
| `.container`, `.contact-button`, `.qr-trigger-button` | 있음 (옅게, 이중 레이어) | 일부(`.qr-trigger-button`만 테두리 병행) |
| `.card`, `.ministry-card-link`, `.qr-sheet-canvas-wrap` | 없음 | 있음 (1px) |
| `.qr-sheet`(Bottom Sheet), `.toast` | 있음 (진하게) | 없음 |

## shadcn 기본 권장과의 의도적 차이

shadcn/ui의 기본 규칙은 "고정 요소(카드/버튼/입력창)는 테두리만, 뜨는 요소만 그림자"다. 이 프로젝트는 **버튼과 컨테이너에도 그림자를 유지하기로 결정했다** (디자인 아이덴티티 적용 시 사용자 확인 — 시각적 변화 없이 현재 톤을 유지). 즉 두 방식이 대상별로 섞여 있다:

- **카드류(`.card`, `.ministry-card-link`)** — 그림자 없이 테두리 1px로만 구분 (shadcn 기본과 동일)
- **버튼·컨테이너(`.contact-button`, `.qr-trigger-button`, `.container`)** — iOS 스타일의 이중 레이어 그림자를 유지 (shadcn 기본과 다름, 의도적 예외)
- **화면을 덮는 요소(`.qr-sheet`, `.toast`)** — 진한 그림자 (shadcn 기본과 동일)

이 구분 기준을 "카드는 얇고 리스트형이라 그림자 없이 테두리로, 버튼/컨테이너는 플로팅 액션이라 입체감 있는 그림자로"라는 한 문장으로 요약해 유지한다.

## 값

- 카드 그림자: 없음 (`--border`로만 구분)
- 버튼/컨테이너 그림자 (옅은 단계): `0 8px 32px rgba(20, 21, 26, 0.2), 0 2px 8px rgba(20, 21, 26, 0.1)`
- 뜬 요소 그림자 (진한 단계): `.qr-sheet`는 `0 -8px 32px rgba(20, 21, 26, 0.2)`(위로 뜨는 시트라 그림자 방향이 반대), `.container`는 `0 8px 32px rgba(20, 21, 26, 0.12)`
- 그림자 색: 전부 `rgba(20, 21, 26, α)` — 채도 있는 그림자 없음, 2단계로 정리됨(옅음/진함)

## 체크리스트
- [x] 세 가지 중 정확히 하나를 골랐는가 — 레이어 기준(고정 vs 뜨는 요소)으로 구분, 단 대상별 예외를 한 문장으로 명시
- [x] 나머지는 "쓰지 않는다"고 명시했는가 — 카드류는 그림자 없음 명시
- [x] 그림자를 쓴다면 단계가 2단계 이내인가 — 옅음/진함 2단계
- [x] 다크 테마인데 그림자에 의존하고 있지 않은가 — 다크 테마 없음(라이트 고정)
